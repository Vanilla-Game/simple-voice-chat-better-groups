# Modrinth gallery screenshots

Five native Minecraft screenshots, captured with F2 at 1280 × 720 (16:9).
The suggested titles and descriptions below are ready for the Modrinth gallery.
Adding these files to GitHub does not upload them to Modrinth.

| Order | Screenshot | Title | Description |
| --- | --- | --- | --- |
| 1 | [Player picker](../assets/gallery/01-player-picker.png) | Invite players | Pick a friend to invite. Requires the Fabric add-on. |
| 2 | [Chat invitation](../assets/gallery/02-chat-invitation.png) | Chat invitations | Click Accept to join without a password. |
| 3 | [Group management](../assets/gallery/03-group-management.png) | Group management | See the leader and remove members. Requires the Fabric add-on. |
| 4 | [Join request](../assets/gallery/04-join-request.png) | Join requests | Ask the leader for access. Requires the Fabric add-on. |
| 5 | [Pause and return](../assets/gallery/05-pause-return.png) | Pause and return | Switch to proximity chat and back. Requires the Fabric add-on. |

## Capture environment

- Minecraft 26.1.2, Fabric Loader 0.18.4, Fabric API 0.155.3+26.1.2.
- Simple Voice Chat 2.6.24 and Better Groups 0.13.0 (server and Fabric client).
- Paper 26.1.2 build 74, Java 25, Debian 13, Xvfb and Mesa llvmpipe.
- Two separate clients, local test players Alex and Steve, GUI scale 3.
- An isolated, local-only creative server with a wooden cabin built for the screenshots.
- Microphones muted; both clients connected to the voice server.

These are unedited F2 captures: no added captions, composited controls, or
reconstructed interface. Minecraft's own menu blur and tooltips are preserved.
The group is password protected. For the return screenshot, Alex pauses while
Steve keeps the group open. The join-request screenshot shows Steve hovering
the request button after leaving the group.
