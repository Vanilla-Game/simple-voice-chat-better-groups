# Supported locales

Better Groups provides server chat messages in **15 languages**, selected
automatically from each player's Minecraft language setting. Players on the same
server can receive messages in different languages. English (US) is the default
fallback.

| Language | Native name | Minecraft locale |
| --- | --- | --- |
| Catalan | Català | `ca_es` |
| Czech | Čeština | `cs_cz` |
| Dutch | Nederlands | `nl_nl` |
| English (US) | English (US) | `en_us` |
| French | Français | `fr_fr` |
| German | Deutsch | `de_de` |
| Italian | Italiano | `it_it` |
| Norwegian | Norsk | `no_no` |
| Polish | Polski | `pl_pl` |
| Portuguese (Portugal) | Português (Portugal) | `pt_pt` |
| Russian | Русский | `ru_ru` |
| Spanish (Spain) | Español (España) | `es_es` |
| Swedish | Svenska | `sv_se` |
| Turkish | Türkçe | `tr_tr` |
| Ukrainian | Українська | `uk_ua` |

## Optional Fabric client

The player picker and member controls have translations for these same locales.
Pause / return controls and feedback are currently translated into English and
Russian; the other locales use English for those strings.

Server translations are stored in
[`src/main/resources/lang`](../src/main/resources/lang), and client translations
in [`client-fabric/src/shared/resources/assets/svc_better_groups_client/lang`](../client-fabric/src/shared/resources/assets/svc_better_groups_client/lang).
